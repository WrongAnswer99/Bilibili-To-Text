# 油猴：下载视频、提取文字、打开位置

当前版本 **v0.3.1**，源文件：项目根目录 bilibili-download.user.js。

## 安装

1. 安装并启用 Tampermonkey 扩展。点击油猴图标 → 添加新脚本，删掉默认内容，将项目根目录 bilibili-download.user.js 全文粘贴并保存；更新时直接替换原脚本。刷新 B 站视频页面。
2. 油猴管理面板 → 设置 → **配置模式：高级**，下载模式设为 **浏览器 API**，允许下载权限。
3. 扩展名白名单允许 mp4；分离音视频还需要 m4s。
4. 核对浏览器实际下载目录，关闭每次询问保存位置。面板默认 C:\Users\admin\Downloads。
5. 要使用转换或打开文件夹，本地首次运行 register_protocol.cmd；更换下载目录执行 register_protocol.ps1 -DownloadDirectory "实际目录"；移动项目或更换 Python 后，双击新项目目录中的 register_protocol_force.cmd 更新注册，也可以运行 register_protocol_force.ps1（支持 -DownloadDirectory 和 -Check），或执行 register_protocol.ps1 -Force。

仅使用“下载视频”无需安装或启动本地应用。

## 三个按钮

- **下载视频**：使用当前浏览器登录态下载当前分 P，不打开本地窗口。
- **下载并提取文字**：全部下载完成后调用 bilibilitotext://import，允许浏览器打开应用。本地自动填写并锁定视频路径，使用所选 CPU/GPU 与语音语言识别，默认简体中文（zh）。当前分 P 已完整下载时再次点击会复用文件，适用于浏览器阻止打开应用后的重试。
- **打开文件所在位置**：调用 bilibilitotext://open-folder，在资源管理器中选中已下载文件，不转换。部分下载成功时也可以定位已保存的文件。

“取消”和“复制结果”保留用于控制任务和反馈完整诊断。

浏览器不向脚本确认应用是否启动或转写是否成功，转换结果以本地窗口为准。没有弹窗时允许打开应用提示，并重新点击“下载并提取文字”。

## 本地端与保存位置

本地端仅处理本地视频，不输入网址、不访问下载网站。也可独立打开 start.cmd，填写路径或点击“打开文件...”选视频，再点击“开始转换”。

浏览器传入时，路径已自动填写并设为只读，不能更换；文件选择按钮变为“打开文件所在位置”。转换参数、状态框与右下角“完成”按钮仍然可用。完成按钮左侧的“转换其他视频”可在转换结束后把当前窗口切换到普通模式，清空并解锁路径，恢复“打开文件...”按钮，并在底部同一位置显示“打开输出文件夹”；选择视频后可打开它所在的目录。转换期间不可切换。

视频不搬移、不改名。TXT/SRT 与视频同目录、同名。TXT 每个识别片段一行，SRT 保留分段时间轴；下载文件保留 BV、分 P、时间戳。例如 BV…_时间戳.mp4 对应 BV…_时间戳.txt 和 BV…_时间戳.srt。不再写到项目 output。

优先获取带声音 MP4，优先 720P，以接口实际返回为准。若只有 DASH 或 MP4 分段：
- 仅下载保存原始轨道/分段，浏览器脚本本身不合并。
- 联动转换先由本地 FFmpeg 在下载目录合并成 MP4。
- 合并失败保留下载原件，成功提交后才移除指定的轨道/分段。
- 合并后“打开文件所在位置”仍能找到最终 MP4。

失败或取消不会启动转写，已完成的下载保留。

## 路径与协议

面板目录、浏览器默认目录、config.json 的 download_directory 必须一致。面板输入仅用于显示预期位置，不会改变浏览器保存目录。

协议传文件名与任务参数，不传 Cookie，也不允许任意路径、命令或外部网址。下载后的完整路径由本地从配置目录解析。油猴不保证返回真实完整路径，另存或浏览器改名后以浏览器下载记录为准。

## 诊断与常见问题

“复制结果”包含版本、浏览器、下载模式、BV/CID/分 P、资源主机与路径、失败阶段、底层错误、已完成文件、耗时、完整日志。Cookie、认证信息、响应正文和 CDN 签名值会省略。

- 找不到下载设置：先切换 **高级** 配置模式。
- 白名单错误：允许 mp4 和 m4s。
- 下载失败：查看浏览器下载记录，复制结果反馈。
- 本地文件不存在：核对浏览器目录与 config.json，检查是否另存或改名。
- 打不开应用/文件夹：确认协议注册，允许浏览器打开本地应用。
- GPU 初始化失败：切换 CPU；GPU 模式不会静默回退。
- 切换参数后仍显示旧结果：本地勾选“重新识别”；仅切换简繁体可复用已有正文。
- 同一文件已在转换：等待当前窗口完成。

GM_download 保持不手动设置 Referer；API 请求继续使用当前登录态。此前 v0.1.2 已在用户 Edge / Tampermonkey 5.5.0 中成功下载 BV1GzHh6YEyC，v0.3.1 没有更改这一下载请求策略。

## 语言下拉框

原“简体中文”下拉框现统一为：英语、简体中文、日语、俄语、繁体中文、自动检测；对应 en/zh/ja/ru/zh/auto。默认简体中文。应选择视频中实际说话的语言，不确定时选自动检测；这不是翻译选项。日语等非中文文本不进行 OpenCC 转换。
